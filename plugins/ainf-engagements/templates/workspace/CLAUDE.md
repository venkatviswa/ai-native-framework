# CLAUDE.md: [engagement] workspace

Sensitivity: client confidential. This folder is the source of truth for the engagement; your memory of earlier sessions is not.

## Source of truth, highest first
1. Live evidence: a log, query result, metric or screen the team captured, with a date.
2. A document from the client or a vendor, with a version.
3. What someone said, with their role and the date.
4. Anything you remember. Never cite it; find the source or ask.

When two sources disagree, record both in facts.md, mark the newer one `to confirm` and raise a Q-.

## Always
- Read status.md and the latest journal entry before doing anything.
- Write absolute dates (`2026-10-14`), never "tomorrow" or "next week". Actions need an owner and a date, or `none` with a reason.
- Put each fact in facts.md once, with a label (confirmed, inferred, to confirm) and a source. Other files cite the F-ID.
- Correct by superseding: mark the old entry `superseded by F-12` and add the new one. Never delete or silently rewrite an entry, and never reuse an ID.
- Every decision says who approved it and what would make us reverse it.
- When someone commits to something in a session, add an A- entry in the same pass.
- Link both ways: a decision lists the facts it rests on, and the action it creates cites the decision.
- End every session by updating status.md and adding a journal entry, then run the ledger check.

## Never
- Reassure. Write what the evidence shows and how sure we are.
- Present a hypothesis or an inference as a finding.
- Send anything to the client, or push to a shared remote. Draft it; a person sends it.
- Paste client specifics into an external service, search engine or tool outside the approved list.
- Run a destructive or production-changing action. List it with its preconditions for a named human.
